# Кодлокс — демонстрационный мини-сайт

Чистые HTML, CSS и JavaScript. Без зависимостей, сборки и сервера приложений.

## Запуск

Откройте `index.html` в браузере. Для предсказуемой работы localStorage рекомендуется локальный HTTP-сервер:

```sh
python3 -m http.server 8080
```

После запуска откройте <http://localhost:8080>.

## Возможности

- Главная страница, блоки программ и информации о школе.
- Страница заявки по адресу `/#grant` (при открытии файла — `index.html#grant`).
- Демовход с любыми непустыми логином и паролем, имя пользователя в шапке, личный кабинет и выход.
- Поля заявки из референсов, выбор нескольких льготных категорий, проверка обязательных полей, телефона, почты и даты рождения.
- Автосохранение и восстановление черновика.
- Семь последовательных этапов демонстрационной проверки, индикаторы загрузки и прогресс.
- Окно одобрения с номером решения и всеми данными анкеты.
- Сохранённые решения доступны после перезагрузки через личный кабинет или страницу гранта.
- Адаптивная вёрстка, мобильное меню, управление модальными окнами с клавиатуры, поддержка уменьшенной анимации.
- Переключатель светлого и прежнего тёмного дизайна в шапке. Выбор сохраняется в `kodlox.theme` в localStorage и восстанавливается до отображения страницы; по умолчанию используется светлая тема.

## Данные

Ключи localStorage: `kodlox.account`, `kodlox.grantDraft`, `kodlox.applications`. Хранятся текущий демоаккаунт (логин и пароль), черновик и до 30 последних решений. При выходе полностью очищается localStorage сайта, включая аккаунт, черновик, решения и сохранённую тему. Поля входа и заявки, выбранные категории и показанный результат также сбрасываются, в том числе в других открытых вкладках. После повторного входа данные нужно вводить заново. Автозаполнение форм браузером отключено.

Это локальный прототип: настоящей авторизации, отправки заявки или проверки гранта нет. Пароль по условию хранится открытым текстом в localStorage; используйте вымышленные данные. Для реального продукта необходима серверная авторизация, пароль нельзя хранить таким способом.

## Проверка выхода

После запуска локального сервера откройте <http://localhost:8080/tests/logout.html>. Тест использует вымышленные данные и очищает localStorage этого адреса. Результат `PASS` подтверждает очистку полей и хранилища, удаление гранта, сброс другой вкладки с незавершённой проверкой, повторный вход, отправку новой заявки, перезагрузку и обработку ошибки хранилища.

## Файлы

- `index.html` — страницы, формы и модальные окна.
- `styles.css` — оформление и адаптивная вёрстка.
- `styles_old.css` — прежний тёмный дизайн.
- `theme.js`, `theme.css` — переключение, сохранение темы и общие стили переключателя.
- `app.js` — навигация, демовход, localStorage, заявка и проверка.
- `assets/favicon.svg` — локальная иконка сайта.
- `refs/` — исходные пользовательские референсы, не используются сайтом при запуске.
